- [ ] Implement user registration – Allow users to create accounts with a username, email, and password.

- [ ] Implement logout – Allow users to log out and clear their active session.
- [ ] Add input validation – Prevent invalid usernames, malformed emails, and weak passwords.
- [ ] Prevent duplicate accounts – Ensure usernames and email addresses are unique.

- [ ] Display user statistics – Show the number of posts, followers, and following.
